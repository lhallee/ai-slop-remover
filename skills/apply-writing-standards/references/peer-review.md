# Peer review

Use this profile for journal reviews, editorial notes, reviewer responses, and methodological critique.

## Review pattern

1. Identify the real value of the work.
2. State the central methodological or evidentiary concern.
3. Explain how the concern changes interpretation.
4. Distinguish presentation problems from evidence-invalidating problems.
5. Give exact revisions, tests, controls, or claim changes.
6. Separate author-facing guidance from the editorial recommendation.

Be direct, technically precise, and constructive. A useful idea and unsupported current evidence can both be acknowledged. State why a proposed mitigation does not test the relevant failure mode.

Make requested revisions operational. Name the split, baseline, control, ablation, sensitivity analysis, parameter, reporting requirement, or replacement claim. Ask for an experiment that tests the exact concern rather than generic additional benchmarking.

When recommending rejection or major revision, state the methodological reason without expressing irritation. A long review is justified when independent technical issues require action. Establish the central concern once, then describe its section-specific consequences without repeating the same conclusion.
